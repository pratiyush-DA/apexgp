ApexGraph Architectural Principles

ApexGraph provides clean-room, production-grade code intelligence inspired by Graphify and REA.

Deterministic AST Indexing

Tree-sitter parsers parse Python, TypeScript, and JavaScript into typed AST representations. Code is strictly processed as passive data; repository scripts are never executed.

Evidence & Provenance Tracking

Every graph edge retains source file path, exact line numbers, and original code snippets. Relationships distinguish confirmed AST definitions (confidence 1.0) from heuristic linkages.

Blast Radius Impact Engine

Reverse traversal traces dependencies upward from modified symbols, identifying all impacted files and dynamically locating the unit tests that verify them.

Defense-in-Depth Security

Strict canonical path validation prevents directory traversal. Remote Git ingestion enforces SSRF protections blocking RFC 1918 and cloud metadata endpoints.

Register Repository

Paths are validated against traversal vulnerabilities. HTTPS only for remote repos.
